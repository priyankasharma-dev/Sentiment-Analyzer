# 🎬 Sentiment Analyzer — IMDB Movie Reviews

A Machine Learning project that predicts whether a movie review is **Positive** or **Negative** using NLP techniques.

---

## 🚀 Project Overview

This project uses the IMDB Dataset of 50,000 movie reviews to train a classification model. The goal is to understand the sentiment behind a review using Natural Language Processing and Machine Learning.

---

## 📊 Dataset

- **Source:** [IMDB Dataset — Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
- **Size:** 50,000 reviews
- **Labels:** Positive / Negative (balanced — 25,000 each)

---
